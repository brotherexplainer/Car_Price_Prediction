# Car Price Prediction using Multiple Linear Regression

A machine learning project that predicts used car selling prices using Multiple Linear Regression.

## Project Overview

The goal of this project is to build a machine learning model that predicts the selling price of a used car based on features such as:

- Year
- Kilometers driven
- Fuel type
- Seller type
- Transmission
- Owner type

The project uses the CarDekho dataset and follows a complete machine learning workflow from data preprocessing to model evaluation and prediction.

##  Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Load and explore the dataset
2. Check dataset information and statistics
3. Handle missing values and duplicate records
4. Remove extreme outliers
5. Select independent and dependent variables
6. Convert categorical features into numerical features using one-hot encoding
7. Split the dataset into training and testing sets
8. Train a Multiple Linear Regression model
9. Generate predictions
10. Evaluate model performance
11. Visualize actual vs predicted prices
12. Analyze residuals
13. Predict the price of a new car

## Model Evaluation

The model is evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)

The project also includes:

- Actual vs Predicted Price visualization
- Residual Plot

## Files

- `MLR Project.ipynb` — Jupyter Notebook containing the complete project
- `cardekho.csv` — Dataset used for training and evaluation

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open `MLR Project.ipynb` in Jupyter Notebook or JupyterLab.
4. Run the cells sequentially.
